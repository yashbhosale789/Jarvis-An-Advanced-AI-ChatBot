# Marvel Character Chatbot

This project is a Streamlit-based chatbot that can answer questions about Marvel characters. It uses a PostgreSQL database with the `pgvector` extension to store character data and perform similarity searches on text embeddings generated by the Azure OpenAI service.

## Features

- **Chatbot Interface**: A user-friendly interface to ask questions about Marvel characters.
- **Voice Input/Output**: Interact with the chatbot using your voice.
- **File Upload**: Upload PDF and CSV files to add more data to the chatbot's knowledge base.
- **Character Comparison**: Compare two characters based on their powers and debut year.
- **Character Images**: Display an image of a selected character.
- **Debut Timeline**: View a timeline of character debuts.
- **Marvel Quiz**: Test your Marvel knowledge with a quiz.
- **Multiverse Variants**: Generate creative multiverse variants for characters.
- **Favorites**: Save your favorite characters.
- **Real-Time Updates**: Keep the character embeddings up-to-date.

## Project Structure

- `app.py`: The main Streamlit application file.
- `chat_bot.py`: A command-line version of the chatbot.
- `generate_embeddings.py`: A script to generate and store embeddings for the character data.
- `SQL Queries`: Contains the SQL statements to create the necessary tables in the database.
- `requirements.txt`: A list of the Python packages required to run the project.
- `.env`: A file to store your environment variables (API keys, database credentials, etc.).

## Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd <repository-directory>
    ```

2.  **Create a virtual environment and install the dependencies:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    pip install -r requirements.txt
    ```

3.  **Set up the PostgreSQL database:**
    - Install PostgreSQL and the `pgvector` extension.
    - Create a new database.
    - Run the SQL queries in `SQL Queries` to create the tables.

4.  **Create a `.env` file and add your credentials:**
    ```
    AZURE_OPENAI_API_KEY="your_azure_openai_api_key"
    AZURE_OPENAI_ENDPOINT="your_azure_openai_endpoint"
    AZURE_OPENAI_API_VERSION="2025-01-01-preview"
    AZURE_OPENAI_EMBEDDING_DEPLOYMENT="your_embedding_deployment_name"
    AZURE_OPENAI_GPT_DEPLOYMENT="your_gpt_deployment_name"
    DB_HOST="your_db_host"
    DB_NAME="your_db_name"
    DB_USER="your_db_user"
    DB_PASSWORD="your_db_password"
    DB_PORT="your_db_port"
    ```

5.  **Generate the initial embeddings:**
    - Place your `marvel_characters.csv` and `Marvel_Character_Brochure.pdf` files in the project directory.
    - Run the `generate_embeddings.py` script:
    ```bash
    python generate_embeddings.py
    ```

6.  **Run the Streamlit application:**
    ```bash
    streamlit run app.py
    ```
